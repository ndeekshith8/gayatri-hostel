# Gayatri Girls Hostel — React + JavaScript
This project uses React, JavaScript/JSX and JSON configuration. Styling is written inside `src/main.jsx` as JavaScript objects. There is no CSS file and no TypeScript.

Run locally:
```bash
npm install
npm run dev
```

Build:
```bash
npm run build
```

Deploy:
1. Push this folder to GitHub.
2. Import the repository in Vercel.
3. Select Vite, build command `npm run build`, output directory `dist`.
4. Deploy.
